# Specification

## Summary
**Goal:** Add a prominent "Start Coaching Session" button as the primary call-to-action on the coaching dashboard.

**Planned changes:**
- Add a large, visually prominent "Start Coaching Session" button to the CoachingDashboard component
- Position the button strategically above or alongside the existing quick-start coaching topic cards
- Configure the button to initiate a new coaching session flow when clicked
- Style the button using the existing OKLCH-based color system to ensure it stands out as a primary CTA

**User-visible outcome:** Users see a clear, prominent button on their coaching dashboard that allows them to quickly start a new coaching session, complementing the existing quick-start topic cards.
